# Теорія ІТ-студій у курсі codetech

Уроки 01–10: ліві панелі з прямими посиланнями на теоретичні сторінки Дія.Освіта, без їхніх тестів та завдань.

Урок 01 — з раніше погодженої версії. Уроки 02–10 — оновлені файли з оригінального codetech-main.zip.

Уроки 11–12 не змінювалися, оскільки відповідних анонсів не надано.

Розпакуйте в корінь репозиторію codetech зі збереженням шляхів lesson-XX/index.html. Не видаляйте папку assets.

Примітка: посилання на «Структури даних і алгоритми» у темі 09 отримане з офіційного змісту, але сайт обмежив автоматичну перевірку саме цієї сторінки.
