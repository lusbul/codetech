# Технології програмування

## Як опублікувати на GitHub Pages
1. Розпакуйте архів.
2. Завантажте index.html, hero.png та .nojekyll у корінь репозиторію GitHub (Add file → Upload files).
3. Відкрийте Settings → Pages.
4. Оберіть Deploy from a branch, гілку main і папку / (root), натисніть Save.
5. Дочекайтеся появи посилання на сайт.

index.html і hero.png мають лежати поруч. Сам ZIP завантажувати в репозиторій не потрібно.

Python і JavaScript виконуються на сторінці. Для першого запуску Python потрібен інтернет для завантаження Pyodide. C++ відкривається в Programiz. У JavaScript підтримано print(), console.log() та prompt() із введенням через поле даних.

Готові головна та перша тема. Теми 2–10 — заготовки. Прогрес зберігається лише в браузері учня.
